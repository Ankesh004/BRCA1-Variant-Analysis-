# BRCA1 Variant Analysis

## Overview
This project studies BRCA1 gene variants using bioinformatics tools.

## Objectives
- Predict pathogenic variants
- Analyze protein structure changes
- Study effects on BRCA1 function

## Tools Used
- PolyPhen-2
- SIFT
- PyMOL
- UniProt
- AlphaFold
