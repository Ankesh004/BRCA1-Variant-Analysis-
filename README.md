
# BRCA1 Variant Analysis

## Overview

This project investigates the effects of BRCA1 missense variants using bioinformatics and structural biology approaches.

## Tools Used

* PolyPhen-2
* SIFT
* PyMOL
* UniProt

## Objective

To predict the pathogenicity of BRCA1 variants and analyze their structural impact.
